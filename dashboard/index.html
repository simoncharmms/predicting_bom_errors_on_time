Finding BOM errors before the next maturity phase

A bill of materials is edited for months by many engineers. Errors are found late, when a fix is expensive. The agent reads each BOM snapshot, turns defects into typed violations, ranks the rows an engineer should check, and shows why — then learns from the verdict. This page walks that loop on the real dataset.

The loop

01 · Observe

One opaque error flag becomes eight typed violations

The dataset carries a single erroneous column: something was wrong, somewhere, somehow. A BDQV — BOM data quality violation — is instead typed, localised and timestamped, so it can be explained, routed to an owner and exchanged with other agents. All eight detectors read observable columns only and never the label.

02 · Correlate

The signal is in the combinations, not the single detector

Co-occurring violations on the same row form a signature. The agent mines signatures on training rows only and stores support, hits and lift in the shared registry. A registry hit is cheap, needs no retraining, and is the part of the model that could warm-start a new vehicle generation.

Every alert arrives with its evidence

This is the artefact the engineer receives. 05 · Learn & share

Verdicts change the registry, not just a log file

Each confirm or dismiss is written back with provenance and updates the counters of the signature that produced the alert. Precision stops being a number in a paper and becomes a quantity the system tracks per pattern. Patterns above a lift and support floor are published for peer agents — as BDQVs, not feature vectors, so a Supplier Agent's "this supplier delivers late" can reach this agent without coupling their models.

Knowledge base after the run

Contract rules

  • Append-only with provenance. Agent, model version, confidence and timestamp on every row. Two agents may contradict each other; both statements survive.
  • Retract-your-own-only. No agent can delete another's assertion.
  • Confidence decay. Exponential, 180-day half-life, so an unconfirmed pattern falls out of the high-precision path by itself.
